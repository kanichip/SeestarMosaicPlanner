# Seestar Mosaic Planner

Seestar（S30 Pro / S50 Pro）およびプラネタリウムソフト「Stellarium」と連携し、天体のモザイク撮影計画を作成・転送・管理するためのデスクトップGUIアプリケーションです。

---

## 主な機能

- **Stellarium 連携**
  - Stellarium の現在の画面中心座標（J2000 RA/Dec）をワンクリックで取得。
  - 計算されたモザイクフレーム（各パネルの枠・番号）を Stellarium の画面上にリアルタイム描画・消去。
- **Seestar 自動検出 & 直接接続**
  - 同一ネットワーク内の Seestar デバイスを自動検索・接続。
  - 検出された機種（S30 Pro / S50 Pro）に応じて視野角（FOV）を自動設定（手動変更も可能）。
- **モザイク撮影計画の作成**
  - 行数・列数・オーバーラップ率（%）を指定して各パネルの天球座標を正確に計算。
  - 開始時刻およびパネルごとの露光時間（分）の設定。
- **Seestar への計画直接転送**
  - 作成したモザイク撮影プラン（PLAN）をネットワーク経由で Seestar 本体へ直接送信。
- **ファイル保存・読み込み**
  - 撮影計画の JSON ファイル（Seestar 互換形式）保存および読み込み。
  - 各パネル座標一覧の CSV エクスポート。

## 動作環境・必要要件

- **OS**: Windows / macOS / Linux
- **Python**: 3.9 以上
- **必要な Python パッケージ**:
  - `PySide6` (GUI)
  - `seestarpy` (Seestar 通信ライブラリ)
- **Stellarium**:
  - 「リモートコントロール（Remote Control）」プラグインを有効化し、ポート `8090` でサーバーを開始しておく必要があります。

---

## インストール方法

1. **リポジトリのクローンまたはダウンロード**
   ```bash
   git clone https://github.com/your-username/SeestarMosaicPlanner.git
   cd SeestarMosaicPlanner
   ```

2. **依存パッケージのインストール**
   ```bash
   pip install PySide6 seestarpy
   ```

## 事前準備（Stellarium 設定）

Stellarium と連携する場合、以下の設定を行ってください：

1. Stellarium を起動し、**設定ウィンドウ（F2） > プラグイン** を開きます。
2. 一覧から **「リモートコントロール (Remote Control)」** を選択し、「起動時にロード」にチェックを入れます。
3. Stellarium を再起動（または設定画面から「サーバーを開始」）します。
4. デフォルトポート `8090` で HTTP API が有効になっていることを確認します。

## 使い方

### 1. アプリケーションの起動

```bash
python SeestarMosaicPlanner.py
```

### 2. 望遠鏡と中心座標の設定

1. **望遠鏡の選択 / 接続**:
   - 「Seestar接続」ボタンをクリックすると、同一ネットワーク内の Seestar が検出され、機種に合わせた FOV が自動設定されます。
   - またはドロップダウンメニューから機種（S30 Pro / S50 Pro）を手動選択します。
2. **中心座標の取得**:
   - Stellarium で撮影したい天体を画面中央に捉えた状態で「Stellarium中心取得」をクリックします。
   - RA / Dec を直接数値入力することも可能です。

### 3. モザイクパラメータの設定

1. 行数（Rows）、列数（Cols）、オーバーラップ率（%）を入力します。
2. 「モザイク計算」をクリックすると、各パネルの中心座標がテーブルに一覧表示されます。
3. 「Stellarium描画」をクリックすると、Stellarium 上にモザイクフレームが重畳表示されます。

### 4. 撮影計画の転送 / 保存

1. **撮影設定**:
   - プラン名、撮影開始時刻、1パネルあたりの撮影時間（分）を指定します。
2. **Seestar への転送**:
   - 「Seestar PLAN作成」をクリックしてプランを生成後、「Seestarへ転送」をクリックして本体へ送信します。
3. **ファイル保存**:
   - 「JSON保存」: Seestar 形式の撮影プラン JSON を保存します。
   - 「CSV保存」: 各パネルの座標一覧を CSV ファイルとして出力します。
