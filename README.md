# Seestar Mosaic Planner

Seestar（S30 Pro / S50 Pro / S30 / S50）およびプラネタリウムソフト「Stellarium」と連携し、天体のモザイク撮影計画を作成・転送・管理するためのデスクトップGUIアプリケーションです。

---

## 主な機能

- **Stellarium 連携**
  - Stellarium で選択中の天体座標または画面中心座標（J2000 RA/Dec）をワンクリックで取得。
  - 計算されたモザイクフレーム（各パネルの枠・番号）を Stellarium の画面上にリアルタイム描画・消去。
  - 撮影枠の明るさ（透過度）調整スライダー。
- **Seestar 自動検出 & 直接接続**
  - 同一ネットワーク内の Seestar デバイスを自動検索・接続。
  - 検出された機種（S30 Pro / S50 Pro / S30 / S50）に応じて視野角（FOV）を自動設定（手動変更も可能）。
- **モザイク設定・構図保存**
  - 構図名、南北方向（Cols）、東西方向（Rows）、重複率（%）を指定して各パネルの天球座標を正確に計算。
  - モザイク構図設定の保存・読み込み（`*.smp` ファイル）。
- **PLAN作成 & 撮影終了時刻の自動計算**
  - 開始時間、1パネルあたりの撮影時間（分）、繰り返し回数（ループ回数）、LP_Filter（光害カットフィルター）の有無を設定。
  - パネル数と設定に基づき、撮影終了予定時刻をリアルタイムに自動計算・表示。
- **Seestar への計画直接転送 & JSON自動保存**
  - 「Seestar転送」ボタン1クリックで、構図名に基づいたプランデータ（各パネルの `alias_name` は `{構図名}-P{番号}`）を自動生成。
  - アプリケーション直下の `plans` フォルダへ `{構図名}.json` として自動保存した上で、Seestar 本体へ直接送信。

## 動作環境・必要要件

- **OS**: Windows / macOS / Linux
- **Python**: 3.9 以上
- **必要な Python パッケージ**:
  - `PySide6` (GUI)
  - `seestarpy` (Seestar 通信ライブラリ)
- **Stellarium**:
  - 「リモートコントロール（Remote Control）」プラグインを有効化し、ポート `8090` でサーバーを開始しておく必要があります。

---

## インストール方法

1. **リポジトリのクローンまたはダウンロード**
   ```bash
   git clone https://github.com/your-username/SeestarMosaicPlanner.git
   cd SeestarMosaicPlanner
   ```

2. **依存パッケージのインストール**
   ```bash
   pip install PySide6 seestarpy
   ```

## 事前準備（Stellarium 設定）

Stellarium と連携する場合、以下の設定を行ってください：

1. Stellarium を起動し、**設定ウィンドウ（F2） > プラグイン** を開きます。
2. 一覧から **「リモートコントロール (Remote Control)」** を選択し、「起動時にロード」にチェックを入れます。
3. Stellarium を再起動（または設定画面から「サーバーを開始」）します。
4. デフォルトポート `8090` で HTTP API が有効になっていることを確認します。

## 使い方

### 1. アプリケーションの起動

```bash
python main.py
```

### 2. 望遠鏡と基準座標の設定

1. **望遠鏡の選択 / 接続**:
   - 「Seestar接続」ボタンをクリックすると、同一ネットワーク内の Seestar が検出され、機種に合わせた画角（FOV）が自動設定されます。
   - またはドロップダウンメニューから機種を手動選択します。
2. **基準座標の取得**:
   - Stellarium 上で撮影したい天体を選択（または画面中央に捉えた状態）にし、「選択天体/中心を取得」をクリックします。

### 3. モザイク設定

1. **構図名・パラメータ設定**:
   - 「構図名」（初期値: `MosaicPlan`）、南北方向（Cols）、東西方向（Rows）、重複率（%）を入力します。
   - スライダーで Stellarium 上に表示する撮影枠の明るさ（0%〜100%）を調整できます。
2. **モザイク計算 & Stellarium 表示**:
   - 「モザイク計算」をクリックすると、各パネルの中心座標がテーブルに一覧表示されます。
   - 「Stellariumに表示」をクリックすると、Stellarium 上に撮影枠が番号付きで重畳表示されます（「撮影枠を消去」で消去可能）。
3. **構図の保存 / 読込**:
   - 「構図保存」: 設定した構図（機種、画角、基準座標、行列、重複率、構図名）を `{構図名}.smp` ファイルとして保存します。
   - 「構図読込」: 保存した `.smp` ファイルから構図設定を復元します。

### 4. PLAN作成 & Seestar転送

1. **撮影パラメータの設定**:
   - 開始時間、撮影時間（分）、回数（繰り返し回数）、LP_Filter（光害カットフィルター）を設定します。
   - 設定に応じて「終了予定」時刻がリアルタイムに表示されます。
2. **Seestar への転送**:
   - 「Seestar転送」ボタンをクリックすると、確認ダイアログが表示されます。
   - 転送プランは自動的に `plans/{構図名}.json` に保存され、Seestar 本体へ直接送信されます。
